# Iaeieue Wsl2

## How do I install these formulae?

`brew install iaeieue/wsl2/<formula>`

Or `brew tap iaeieue/wsl2` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "iaeieue/wsl2"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
